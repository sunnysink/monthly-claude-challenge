How it works

Start in the middle. The centre square, Your Biz Brain, is the one that makes the rest run. Set it up first, then every other square has a home to save to and read from.

  1. Pick any square. Tap it, copy the prompt, run it in Claude, and build the system it hands you.
  2. Put it to work. Set it running, save it, or wire it into your tools. The square counts once the thing is actually built and doing its job.
  3. Share it in the Monthly Challenge category in the community, with the square's name as your title. That is what marks it done. Show what you built and one line on what it now saves you.
  4. Five in a row is one entry. Any direction, across, down, or corner to corner. The centre square, Your Biz Brain, is done for you, so two of the lines start with a head start.
  5. Fill more rows, get more entries. Twelve lines exist on this board. Every one you complete is another name in the draw.
  6. One build per square. Each thing you make counts for one square only, and it has to be something you built this month.
$50Cash prize

One winner, drawn on October 1. Every completed line puts your name in once more, so the board rewards finishing a row over collecting scattered squares. Your progress saves on this device, so you can close the tab and pick it back up whenever you have twenty minutes.
